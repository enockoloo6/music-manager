# Database Future Vision

Current core tables:

- songs
- styles
- keyboards
- profiles

Future additions:

## song_audio

Audio recordings and references.

## setlists

Service planning.

## setlist_songs

Ordered songs within a service.

## performance_sessions

Service-specific song settings.

Possible fields:

- song_id
- setlist_id
- musical_key
- tempo
- keyboard_id
- notes

## audit_log

Potential future administrative tracking.

Examples:

- song created
- song edited
- lyrics changed
- audio uploaded
- admin promotion

## favorites

Optional future user feature.

Allows users to bookmark frequently used songs.

## tags

Optional future feature.

Examples:

- worship
- communion
- altar call
- choir special
- youth service

Tags can improve searching later.

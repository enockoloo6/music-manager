# Song Metadata Plan

Release target:

v1.1.1

## Purpose

Lyrics are now becoming a first-class feature.

To support worship planning and future setlists, songs need richer information than just a title.

## New Song Fields

- composer
- theme
- scripture_reference
- default_key
- default_tempo
- song_notes

## Examples

Title:
Only Believe

Composer:
Paul Rader

Theme:
Faith

Scripture:
Mark 9:23

Default Key:
G

Default Tempo:
72

## Benefits

- improved searching
- worship preparation
- easier setlist creation
- future reporting
- performance session support

## Future Search Examples

Search by:

- title
- lyrics
- composer
- scripture
- theme

## Relationship to Setlists

Future worship sessions can inherit:

- default key
- default tempo

and override them when needed.

## Relationship to Audio

Metadata helps users identify the correct recording when multiple audio versions exist.
